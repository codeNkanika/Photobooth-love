# 🎬 CineWatch

A movie watchlist application built using Python and PostgreSQL.

## 🌐 Live Demo

🔗 **Website:** https://celebrated-douhua-89602f.netlify.app/

## Features

- Add Movies
- View Movies
- Mark as Watched
- Rate Movies
- Delete Movies

## Technologies Used

- Python
- PostgreSQL
- psycopg2
